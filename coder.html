Help & Tips

    

      
    
        
  1. Add blocks in the left workspace.
    2. 
        
  2. See generated code in the right tabs.
    3. 
        
  3. Click Connect. Choose your ESP32 port.
    4. 
        
  4. Upload to send MicroPython code as main.py. The board restarts and runs it.
    5. 
      

      
Not running MicroPython? Flash MicroPython firmware using the Flash .bin button below the serial monitor. Pick a MicroPython .bin file for ESP32. After flashing, reconnect and upload.

      
Troubleshooting: close other serial apps, try another cable, hold BOOT and tap EN on some boards, install drivers, try a different baud if text looks garbled.

    

  

  
  
    
Firmware & Flashing

    

      
You can flash a MicroPython firmware .bin to your ESP32 using Web Serial and esptool.js. Click Flash .bin in the device panel and select a file. This will erase and write the chip. After flashing, press EN/Reset on the board and click Connect again.

      
We do not bundle any firmware. Download from the official MicroPython site for your board.
